# I-Wish

I-Wish is a Java desktop application for creating wish lists,
adding friends, viewing friends' wish lists, and contributing
to wishlist items.

## Technologies

- Java
- JavaFX
- MySQL
- JDBC
- IntelliJ IDEA

## Database Setup

1. Install MySQL and MySQL Workbench.

2. Create the database by importing:

   database/i_wish.sql

3. The database name is:

   i_wish

4. Configure the MySQL password using the environment variable:

   IWISH_DB_PASSWORD

## Run the Application

1. Start the I-Wish Server.

2. Make sure MySQL is running.

3. Set the `IWISH_DB_PASSWORD` environment variable.

4. Run `LoginApp`.
